# Описание работы веб-приложения

На основе разработанной HTML-верстки страницы «Контакты» создано
простое веб-приложение. Приложение настроено таким образом, что при 
обращении пользователя по любому URL с использованием HTTP GET-запроса 
сервер возвращает страницу «Контакты».

Алгоритм работы приложения:

1. Пользователь отправляет GET-запрос на любой доступный адрес приложения.
2. Сервер принимает запрос и обрабатывает его единым маршрутом.
3. Независимо от указанного пути сервер формирует ответ с HTML-страницей «Контакты».
4. Браузер пользователя отображает страницу «Контакты».

В результате приложение выполняет функцию единой точки отображения
страницы «Контакты» для всех GET-запросов.
